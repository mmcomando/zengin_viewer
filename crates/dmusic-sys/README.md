# dmusic-sys

Minimal wrapper around [GothicKit/dmusic]. It loads DirectMusic segments
(`.sgt`) with their `.sty` and `.dls` references and renders PCM.

## Vendored library

The C sources are expected at `vendor/dmusic` as a git submodule.


## Rust bindings

`src/bindings.rs` is generated by the separate `xtask` binary and **committed
to the repository**. The library build (`build.rs`) only compiles the C sources;
it never runs bindgen.

Regenerating is an explicit developer step:

```sh
cd crates/dmusic-sys
just bindings   # only regenerate src/bindings.rs
just build      # build the crate
```

Generation requires the initialized `vendor/dmusic` submodule and `libclang`.
Commit the resulting `src/bindings.rs` together with the submodule bump.

[GothicKit/dmusic]: https://github.com/GothicKit/dmusic
